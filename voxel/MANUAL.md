# 零、滚雪球

**这个世界的意义不在「建出一栋楼」，在「积累」。**

## 开工前先看仓库

```
voxel_query()
  → blueprints：前人留下了什么建筑
  → macros：前人留下了什么技法
```

**有现成的就复用，不要重造。**

## 收工前留东西

```js
voxel_build({ commands: "...", saveAs: "三层塔楼" })   // ← 就加这一个参数
```

**电脑自动处理**：内容重复→跳过；同名不同内容→v2/v3；超过 3 版→删最老；没给名字→「建筑-001」。

**不给 `saveAs` = 不存。**

# 二、两种建法

## 建法 A：用 frame（推荐，90% 的建筑）

**先说地，再说方位。你不需要算任何坐标。**

```
frame 90 90 113 109       ← 这块地：x 90~113，z 90~109
floor 2                   ← 铺地
wall 北 高8 厚2           ← 四面墙
wall 南 高8 厚2
wall 东 高7 厚2
wall 西 高7 厚2
roof 收分1 层4 每层1      ← 屋顶自动接在墙顶
door 南 中心 宽6 高6      ← 门自动开在南墙正中
```

**这就是一栋完整的房子。八个数字，全是尺寸，没有一个是坐标。**

### 方位指令表

| 指令 | 写法 | 说明 |
|---|---|---|
| `frame` | `frame X1 Z1 X2 Z2` | 立轴。之后的方位指令都相对它 |
| | `frame off` | 取消，回到纯坐标模式 |
| `floor` | `floor 材质2 [y]` | 铺满整块地 |
| `ceil` | `ceil 材质1 [y]` | 盖顶，默认接墙顶 |
| `wall` | `wall 南 高8 厚2 材质1` | 贴着某边立墙 |
| `roof` | `roof 收分1 层4 每层1 材质2` | 阶梯屋顶，默认接墙顶 |
| `door` | `door 南 中心 宽6 高6` | 开门洞 |
| `win` | `win 北 左3 宽3 高3` | 开窗 + 自动加窗台 |
| `col` | `col 南 间距4 高6` | 沿边立一排柱子 |

### 参数三种写法都认

```
wall 南 高8 厚2 材质1     ← 键值对（推荐，顺序无所谓）
wall 南 8 2 1            ← 纯数字（顺序固定）
```

**键名中英文都认**：`高/h`、`厚/t`、`材质/mat`、`y/base`、`层/levels`、`每层/step`、`收分/inset`、`宽/w`。

### 偏移的写法

```
door 南 中心 宽6 高6      ← 正中
door 南 左3 宽6 高6       ← 从左边数 3 格
door 南 右3 宽6 高6       ← 从右边数 3 格
door 南 5 宽6 高6         ← 等效于 左5
```

## 建法 B：用坐标（自由形状）

**只有需要斜的、不规则的、跨出 frame 的东西时才用。**

```
box X Y Z 宽 高 深 材质          实心
hollow X Y Z 宽 高 深 材质       空心盒（墙厚 1）
line X1 Y1 Z1 X2 Y2 Z2 材质 [厚]
stairs X Y Z 步数 宽 材质 [升]
sphere CX CY CZ 半径 材质
clear
```

材质：**24 色**

```
0  红    1  黄    2  蓝    3  白    4  橙    5  绿
6  浅红  7  浅黄  8  浅蓝  9  浅绿
10 深红  11 深黄  12 深蓝  13 深绿
14 浅棕  15 棕    16 浅灰  17 深灰  18 黑
19 粉    20 青    21 紫    22 橄榄  23 肤色
```

# 三、标准流程

```
1. voxel_query    看世界里有什么、哪个区空着
2. voxel_rate     要演示生长动画就调 2~8（默认 60 太快）
3. voxel_build    建
4. voxel_merge    如果分了几次建，固化成整体 ← 重要
5. voxel_query    确认真的建成了
```

## 为什么要固化（voxel_merge）

**分几次建出来的楼是好几个独立建筑。** 拖动、旋转、拆掉存图纸都只作用于其中一个 —— 拖地基会把它拖走，上层留在原地。

**建完就合并：**

```js
voxel_merge({ ids: ["地基", "主墙", "屋顶"], targetId: "我的塔" })
```

**只改归属指向，不动任何坐标。合并后拖/转/拆都是一个整体。**

# 四、宏仓库（复用骨架）

```
voxel_macro({ action: "list" })                     ← 看目录
voxel_macro({ action: "run", name: "台基",
              params: { x: 70, z: 70, w: 24, d: 20 } })
voxel_macro({ action: "save", name: "我的屋顶",
              template: "box {x} {y} {z} {w} 1 {d} 2",
              params: { x: 80, y: 10, z: 80, w: 20, d: 20 },
              desc: "平顶" })
```

**8 个内置骨架随插件出厂，永远在：**

台基 / 方墙 / 柱列 / 阶梯顶 / 台阶 / 门洞 / 窗洞 / 院墙

**用它们拼装，比从零写快得多。**

# 五、把图片变成方块

```
voxel_image({
  path: "照片.png",          // PNG 或 JPEG，绝对路径或相对工作目录
  x: 20, z: 80,              // 左下角位置
  cols: 64, rows: 64,        // 网格密度（不给就按图比例自动算）
  crop: "21,21,448,616",     // 可选：先裁掉边框 x0,y0,x1,y1
  buildId: "我的画",
  saveAs: "我的画"
})
```

**支持**：PNG（8 位）、JPEG（基线 + 渐进）
**不支持**：HEIC / WebP / GIF → 明确报错，让用户先转换

## 密度怎么选

| 网格 | 块数 | 效果 |
|---|---|---|
| 24×32 | 768 | 只有轮廓 |
| 44×44 | 1,936 | 能看出五官 |
| **64×64** | **4,096** | **推荐上限** |

**世界只有 64 格高（Y 0~63），所以图高最多 64。**

## 什么图效果好

```
✅ 人像、插画、像素画、logo、色块分明的图
❌ 风景照、渐变、大雾/逆光场景
```

**原因**：只有 24 色，渐变会被压成色块。

## 24 色里有深色

```
0-5   红黄蓝白橙绿（魔方六色）
6-9   浅红 浅黄 浅蓝 浅绿
10-13 深红 深黄 深蓝 深绿     ← 深色头发靠这几个
14-23 浅棕 棕 浅灰 深灰 黑 粉 青 紫 橄榄 肤色
```

# 六、三个仓库

| 仓库 | 存什么 | 怎么用 |
|---|---|---|
| 砖头 | 拆下来的散料，按材质计数 | `voxel_query` 的 `bricks` |
| 图纸 | 整栋建筑（相对坐标） | `blueprints` 查，`voxel_place` 放回 |
| 宏 | 带参数的指令模板 | `macros` 查，`voxel_macro` 执行 |

**拆除时：**
- **固化过的建筑** → 存一张完整图纸进仓库，能原样放回
- **没固化的零散件** → 只变散砖，不留图纸（施工废料不值得留）

**所以「固化」是留图纸的前提。** 不固化就拆，东西就真的变成砖了。

## 清理仓库

```
voxel_blueprint_remove({ name: "简易小屋" })   ← 删一张
voxel_blueprint_remove({ all: true })          ← 清空全部
```

**试作品、过时的草稿，用完就删掉。** 仓库堆满没人用的图纸，后来者就找不到有用的了。

宏也一样：`voxel_macro({ action: "save", ... })` 存，删宏走同一条通道。

# 六、硬规矩

1. **先 query 再动手**
2. **不要都堆中心**
3. **优先用 frame，不要手算坐标**——手算一定出错
4. **分几次建完就固化**
5. **失败如实说**——`ok: false` 就是没成，别编

## 你做不到的

- ❌ 改渲染代码（要重启）
- ❌ 操作天气（只能让用户拖滑杆）
- ❌ 看画面（只能靠 `voxel_query` 读数字）

## 界面上有什么（你调不了）

右上角：**固化** / 收纳 / 放回 / 拆除 / 重置 / 仓库

**「固化」= 把所有建筑合成一个整体，并立刻存进图纸仓库。**

点它会弹一个命名框：给这栋楼起个名字，回车确认。
固化之后：整体移动/旋转生效，图纸仓库里多一份完整档案，世界里的建筑还在。

**「展示大陆」关掉时建筑悬在草地/海面上** —— 特性，不是 bug。
