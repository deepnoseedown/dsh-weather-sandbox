# 建筑公理

**不要记建筑，记怎么推导建筑。** 抄一栋泰姬陵，下次遇到哥特教堂你又不会了。

---

# 一、递归细分

> **一个空间，沿【长边】切成两块，然后对每块重复。**

所有平面布局都源于此：房间、街区、地块、楼层。

**两个必须遵守的：**

**① 切长边，不切固定轴**——永远横切会把宽扁空间切成没法用的窄条。

**② 最小尺寸用「宽和深」，不用「面积」**——面积 >=10 会让 10×1 通过，但它是废的。

**落到方块**：切一刀 = 立一道 1 格厚的墙；递归到底 = 每个终末矩形是一个房间。

---

# 二、中心缩分

> **尺寸缩小时按比例向中心缩，不是减面积。**

```
新宽 = 宽 - inset*2
新原点 = 原点 + inset
```

**为什么用比例**：退线 2 米就直接是「每边少 2 格」，不用反推面积再换算。**比例读出来就是设计意图。**

长出：收分、退台、台基、退线。

---

# 三、层叠收分

> **每层比下层小 inset，并且升高 stepH。**

```
levels=5, stepH=1, inset=1  → 缓坡台地
levels=5, stepH=1, inset=2  → 陡金字塔
levels=5, stepH=3, inset=1  → 宝塔（层高缩得慢）
levels=10, stepH=1, inset=0 → 直筒塔
```

**三个参数定一切。同一个规则，换参数就是不同建筑。**

长出：金字塔、阶梯屋顶、宝塔、看台、台地、牌坊。**中式攒尖顶是它的特例**（层多、收得快）。

---

# 四、轴向收分

> **只在一个方向收，另一个方向不变。**

和公理三的区别：三号是四面都收（金字塔），这个是**单向收**。

长出：**船头船尾**、塔的收腰、扶壁、拱的侧腿、斜塔。

造一艘船就是它：龙骨窄→船底渐宽→船舷最宽→船头收尖。

---

# 五、中空成壁

> **外壳留厚度，内部掏空。**

三种掏法：全掏（盒子/船壳）、掏顶（池子/院子）、掏侧（门洞/窗/走廊）。

**不掏空的代价**：块数 ×3~8、里面不能进人、从上面看是个填满的坑。

**判断标准：要能进人就必须中空。只要能站人的地方，就必须是空气。**

**实现注意**：指令集没有减法。要「中空」不是先填实再挖，而是**直接用边拼墙**——四条 `box` 围一圈，或 `hollow`（墙厚 1 格）。

---

# 六、深度轮换

> **不同层级的细分，用不同的规则。**

全用同一规则 = 一堆同样大小的方块，像棋盘不像城市。

```
第 0 层切大道（宽 14，最小 80）
第 1 层切街道（宽 6，最小 20）
第 2 层切地块（宽 0，最小 9）
```

**反过来也有用**：想要均匀方格网（棋盘城市）就所有层用同一规则。

长出：曼哈顿式街区、主次分明的路网、从大到小的层次。

**在单栋建筑上也能用**：主楼比次楼高、屋檐比墙体多出一圈——这也是深度轮换。

---

# 七、种子可复现

> **同一个种子，必出同一个结果。**

用户说「再来一个类似的」时，你得能复现。**所有随机数都来自同一个种子**，不要每步各自取随机。

附带好处：改种子第 3 步 → 其余不变 = 快速变异出新风格。

---

# 八、比例与尺度

## 人体尺度

```
1 格 = 0.5 米，一个人 1.8 米 = 3.6 格

门高 >= 4 格        层高 >= 6 格
台阶 高 1 深 2      走廊宽 >= 4 格
```

**建之前先问：人能站进去吗？**

## 视觉比例

| 底宽 : 高 | 用在哪 |
|---|---|
| 1 : 3 | 瘦高的塔 |
| 1 : 1.5 | 正常的楼 |
| 2 : 1 | 宽扁的殿 |
| 屋檐外挑 = 底宽/10 | 中式屋顶 |

**这些是起点不是定律。想不寻常就先破了它，但要知道你在破什么。**

# 九、怎么用

## 拆一栋没建过的楼

```
问：一座中式宝塔？

① 公理三 → 骨架：7 层，每层缩 1，层高 2
② 公理二 → 每层内部再缩一圈做挑檐
③ 公理五 → 每层掏空，留墙厚 1
④ 公理一 → 底层切开成门厅 + 楼梯间
⑤ 公理四 → 四角做斜撑
⑥ 公理六 → 屋檐比墙体多出一圈
⑦ 公理七 → 记种子，用户要"类似的"时复现
```

## 拆一座城

```
① 公理一+六 → 大城市切大道、小城切街道、再切地块
② 公理二   → 每块地退线留人行道
③ 公理三   → 每栋楼按层数做高度差
④ 公理五   → 每栋楼中空能进人
⑤ 公理七   → 种子固定，整座城可复现
```

# 十、一句话

> **一根方块是「笔」，七条公理是「透视」。**
> 学会透视，画任何东西都对。只学画一座房子，换一座就不会了。

---

# 十一、怎么贡献新公理

摸索出**一条能反复用、不绑定具体建筑**的规则时：

1. 确认它至少能造出 3 种不同的东西
2. 写清：它是什么、为什么、参数、能长出什么
3. 编号接着往下排

**不要往里加「怎么建某个具体建筑」——那是例子，不是公理。具体建筑沉淀在图纸/宏仓库里。**
